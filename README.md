# kizuna

Sitio de **KIZUNALM**: atención al cliente ordenada, publicaciones que venden y páginas web para emprendedores en Chile, con planes de precio final y reserva por abono del 50 % con Webpay.

| Carpeta | Qué hay |
| --- | --- |
| [`kizunalm-web/`](kizunalm-web/) | El sitio (Astro + Node, pago con Webpay Plus). Comandos, despliegue y variables en su [README](kizunalm-web/README.md); diseño en [DESIGN.md](kizunalm-web/DESIGN.md). |
| [`research/`](research/) | Estudio de mercado de 15 sitios chilenos que venden servicios parecidos. |
| `kizunalm (7).html` | El HTML original del que partió el sitio, como referencia. |

```
cd kizunalm-web
npm install
npm run dev
```
